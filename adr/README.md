# Architecture Decision Records

ADRs preserve architecture context and prevent the repository from becoming a collection of unexplained diagrams.

## Template

```text
# ADR-NNN: <Decision>

Status: Proposed | Accepted | Superseded | Rejected
Date: YYYY-MM-DD

## Context
What forces, constraints, and requirements led to this decision?

## Decision
What are we choosing?

## Alternatives considered
What credible alternatives were evaluated?

## Consequences
Positive, negative, operational, security, cost, and migration consequences.

## Validation
How will the decision be tested or measured?
```
