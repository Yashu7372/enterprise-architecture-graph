# Solution Architect Learning Path

## Goal

Translate business capabilities and constraints into secure, scalable, operable enterprise solutions.

```text
Business capability
→ requirements / NFRs
→ domain decomposition
→ API and integration architecture
→ event architecture
→ data architecture
→ cloud / platform
→ security
→ reliability
→ observability
→ governance
→ migration strategy
→ AI transformation
```
