# AI Solution Architect Learning Path

Design enterprise AI solutions that satisfy business requirements, NFRs, security, governance, cost, and operational constraints.

```text

→ integration

→ security

→ agents / tools
→ evaluation
→ governance
→ observability
→ cost / scale
→ production operations
```
