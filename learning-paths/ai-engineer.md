# AI Engineer Learning Path

## Goal

Build production AI systems rather than only model demos.

```text
Python / APIs
→ LLM fundamentals
→ embeddings
→ retrieval
→ RAG
→ evaluation
→ structured output
→ tool use
→ MCP
→ context engineering
→ durable agents
→ AI observability
→ production AI platforms
```

## Evidence expectation

For each major capability: one architecture note, one runnable lab, one failure test, and one interview explanation.
